دخترِ ماه — نسخهٔ سایت + داشبورد مدیر

فایل‌ها:
- index.html: سایت عمومی
- music/Rozet-Mobarak.mp3: آهنگی که خودت فرستادی
- server.js: سرور، API و پنل مدیر
- package.json: وابستگی‌های لازم

انتشار روی Render (با گوشی):
۱) کل پوشه را در یک مخزن GitHub قرار بده (فایل ZIP را می‌توانی استخراج کنی و فایل‌ها را در مخزن آپلود کنی).
۲) در Render: New + Web Service و مخزن را وصل کن.
۳) Build Command: npm install
۴) Start Command: npm start
۵) Environment Variables اضافه کن:
   ADMIN_PASSWORD = یک رمز قوی و یکتا که جای دیگری استفاده نمی‌کنی
   SESSION_SECRET = یک رشتهٔ تصادفی طولانی (حداقل 32 کاراکتر)
   NODE_ENV = production
۶) بعد از Deploy، سایت در نشانی Render بالا می‌آید.

آدرس پنل مدیر:
https://آدرس-سایت-تو.onrender.com/admin
پس از ورود موفق، داشبورد باز می‌شود.

مهم:
- بدون تنظیم ADMIN_PASSWORD و SESSION_SECRET سرور بالا نمی‌آید؛ این برای امنیت است.
- داده‌ها در حال حاضر در data.json ذخیره می‌شوند. در سرویس میزبانی رایگان ممکن است فایل محلی با راه‌اندازی مجدد از دست برود؛ برای نگهداری دائمی باید دیسک پایدار یا دیتابیس متصل شود.
- فرم رضایت سایت مشخص می‌کند چه داده‌هایی ذخیره می‌شوند. اطلاعات فقط در صورت فعال‌بودن رضایت ذخیره می‌شود.
- این سیستم هویت واقعی یا ایمیل افراد را شناسایی نمی‌کند؛ فقط اطلاعاتی را نشان می‌دهد که خودشان وارد می‌کنند.
- پیش از استفاده واقعی، با حساب خودت یک تست انجام بده و در داشبورد مطمئن شو ثبت‌ها ظاهر می‌شوند.
